# APITube News API

> APITube provides a comprehensive News API that aggregates and structures news articles from thousands of sources worldwide. The platform offers real-time news data, advanced filtering, sentiment analysis, and full-text search capabilities. Our API is designed for developers, researchers, and businesses who need reliable access to global news data.

## Overview

APITube News API is a powerful platform for accessing structured news data from around the world. The service provides:

- Real-time news aggregation from 500,000+ verified sources
- Support for 60+ languages
- Coverage of 180+ countries and territories
- Advanced filtering by topics, entities, sentiment, and more
- Historical news data access
- Sentiment analysis and NLP processing
- Export capabilities (JSON, XML, CSV, XLSX, TSV)

## Key API Endpoints

Base URL: `https://api.apitube.io`. All endpoints return JSON by default; XML, CSV, XLSX, TSV exports are also supported.

- `GET /v1/news/everything` — Search across all indexed articles with advanced filters (keywords, sentiment, entities, language, country, category, date range, source)
- `GET /v1/news/top-headlines` — Latest breaking news headlines, filterable by country and category
- `GET /v1/news/article` — Retrieve a specific article by Article ID
- `GET /v1/news/story` — Retrieve a story (clustered articles) by Article ID
- `GET /v1/news/category` — Get articles by category (IAB taxonomy)
- `GET /v1/news/topic` — Get articles by topic
- `GET /v1/news/industry` — Get articles by industry
- `GET /v1/news/entity` — Get articles mentioning a specific entity (person, organization, location)
- `GET /v1/news/stream` — Real-time article stream via Server-Sent Events (SSE)
- `GET /v1/news/trends` — Trending values for a given field with time-bucket comparison
- `GET /v1/suggest/entities` — Autocomplete search for entities
- `GET /v1/balance` — Check API key credit balance

Authentication: pass your API key via `api_key` query parameter, `X-API-Key` header, or `Authorization: Bearer YOUR_API_KEY` header. See [docs.apitube.io](https://docs.apitube.io) for complete reference.

## Browser Tools (WebMCP)

When this site is opened in a WebMCP-capable browser, the following tools are registered on `navigator.modelContext` and can be invoked directly by AI agents acting on the page:

- `search_site` — full-text search across documentation, blog, help center and datasets; returns matching pages with title, URL and snippet.
- `navigate` — open a key page (home, pricing, product, compare, demo, blog, cookbook, datasets, help-center, careers, forum, contact, search).
- `try_news_api_demo` — run a sample News API query and return one example article to preview the response shape (no authentication required).
